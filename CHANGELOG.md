# AI Tools Hub

Каталог ИИ-сервисов с честными лимитами, отметкой про VPN и живым статусом API.
Ключевая особенность — **история изменений**: сайт помнит, как менялись условия
у каждого сервиса, и показывает это посетителям.

## Что внутри

| Часть | Назначение |
|---|---|
| `server.js` | Express + SQLite. 25+ эндпоинтов, сессии, авторизация, админка |
| `public/index.html` | Главная: квиз подбора, статус API, каталог, стек-билдер |
| `public/tool.html` | Страница инструмента: рейтинг, история изменений, комментарии |
| `public/compare.html` | Сравнение до трёх сервисов с вердиктом |
| `public/admin.html` | Редактор каталога: правка лимитов без изменения кода |
| `public/changelog.html` | История версий проекта |
| `deploy/` | Скрипты установки на Debian и systemd-юнит |
| `database.db` | SQLite. Не в git — на сервере своя копия |

## Локальный запуск

```bash
npm install
npm start
```

Откроется на `http://localhost:3000`. Нужен Node.js 22 или новее — проект
использует встроенный модуль `node:sqlite`.

При первом старте 24 инструмента переносятся из стартового набора в таблицу
`tools`, дальше правки идут через админку.

## Установка на сервер

```bash
git clone https://github.com/phantom-lancer/AIToolsHub.git
cd AIToolsHub
chmod +x deploy/install.sh
sudo ./deploy/install.sh
```

Скрипт поставит Node.js 24, зависимости, systemd-юнит и nginx на 80-м порту.
Проект разворачивается в `/opt/ai-tools-hub`, база — `database.db` рядом с ним.

## Обновление

```bash
cd /opt/ai-tools-hub && git pull && sudo ./deploy/update.sh
```

База при обновлении не затрагивается. Сервис перезапускается сам,
`Restart=always` в юните поднимает его и после перезагрузки сервера.

## Публичный доступ

Cloudflare Tunnel в этой сети не работает — соединение до Cloudflare
обрывается, сервер получает статус `operational` в логе, но трафик не проходит,
Cloudflare отдаёт ошибку 1033. Поднимать `deploy/tunnel.sh` имеет смысл только
в сетях без этой блокировки.

Основной способ доступа — VPN провайдера: `http://10.31.0.55`. Конфиг
WireGuard скачивается в панели, его можно передать другому пользователю.

## Как работает статус API

Каждые 5 минут сервер делает реальные HTTP-запросы к API пяти провайдеров и
пишет результат в таблицу `uptime`. Страница показывает текущее состояние и
аптайм за 24 часа. Таймаут отличается от падения сервиса: таймаут почти всегда
означает блокировку маршрута провайдером, а не поломку на стороне сервиса.

## Права и доступ

Первый зарегистрированный пользователь становится администратором. Он видит
кнопку «Правки» в шапке и может редактировать каталог в `/admin.html`.
Остальные прав не имеют.
